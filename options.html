A rule needs a host, an exact attribute key, and a regex for the attribute value. For example: on mail.yahoo.com, remove any element matching section whose data-test-id matches novation.*. Yahoo's current markup uses a section; change the selector if yours differs.

Import / export

Rules are stored locally in Chrome. Copy this JSON to back them up, or paste a JSON array and replace the current rules.

Div Hider only injects its content script into hosts that have an enabled rule and site access. Chrome asks for access to each host the first time you save a rule for it; the toolbar icon stays disabled on other sites. Rules with URL regexes are also skipped immediately when the URL does not match. Open shadow DOM is not traversed.
