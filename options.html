A rule needs a host and a CSS selector. For example, remove any section on mail.yahoo.com whose data-test-id starts with novation: section[data-test-id^="novation"]. Use :has() to match a parent by its child, e.g. li:has(> a[custom_att="fancy"]).

Import / export

Rules are stored locally in Chrome. Copy this JSON to back them up, or paste a JSON array and replace the current rules.

Div Hider only injects its content script into hosts that have an enabled rule and site access. Chrome asks for access to each host the first time you save a rule for it; the toolbar icon stays disabled on other sites. Selectors are evaluated with the browser's built-in querySelectorAll/matches, including :has(). Rules with URL regexes are skipped immediately when the URL does not match. Open shadow DOM is not traversed.
